# 🏦 Финансовый анализатор транзакций

**Python-приложение для анализа банковских операций**, которое:
- Читает транзакции из Excel
- Формирует сводку по картам и топ-тратам
- Генерирует приветствие по времени
- Получает курсы валют и акций
- Считает кэшбэк, инвесткопилку и строит отчёты

---

## Установка:

Убедитесь, что на вашей системе установлен Python 3.8+

Команда для клонирования репрозитрия git clone https://github.com/natali23natali26-tech/Pyproject1/tree/develop

Каталог проекта: cd project1.1.1

Установка зависимостей: pip install -r requirements.txt

## Использование:

📁 Модуль **src/utils.py**

💡 **get_greeting(dt_str: str) -> str**  генерирует приветствие в зависимости от времени суток.

```
Пример:
get_greeting("2024-01-15 14:30:00")  # → "Добрый день"
```

💡 **read_transactions_from_excel(excel_path: str) -> list[dict]** считывает транзакции из Excel-файла и возвращает список словарей.

- Использует pandas.read_excel()

- Преобразует каждую строку в словарь: { "Дата": "...", "Сумма": -1500, ... }

- Логирует количество загруженных транзакций

- Обработка ошибок:

FileNotFoundError → логирует ошибку, возвращает пустой список. 

Любая другая ошибка → логирует, возвращает []

💡 **get_conversion_rate(from_currency: str, to_currency: str, amount: str) -> Optional[float]** конвертирует сумму из одной валюты в другую через API.

- Использует:

https://api.apilayer.com/exchangerates_data/convert

- Параметры:

from_currency — исходная валюта (например, "USD")

to_currency — целевая валюта (например, "RUB")

amount — сумма (строка)

- Возвращает:

float — сконвертированная сумма (округлённая до 2 знаков)

None — при ошибке

- Логирование:

Записывает успешные и неудачные запросы.


💡 **get_currency_rates(curr_list: list[str]) -> list[dict]** получает курсы валют из списка относительно рубля.

- Как работает:

Для каждой валюты из curr_list вызывает get_conversion_rate(..., to_currency='RUB', amount='1')

Формирует список словарей: [{"currency": "USD", "rate": 92.5}, ...]

```
Пример:
get_currency_rates(['USD', 'EUR'])  # → [{"currency": "USD", "rate": 92.5}, ...]
```


💡 **get_stock_prices(stock: str) -> Optional[float]** получает текущую цену акции через API Twelvedata.

- Использует:

https://api.twelvedata.com/price?symbol=AAPL&apikey=...

- Параметры:

stock — тикер акции ("AAPL", "TSLA" и т.д.)

- Возвращает:

float — цена в USD (округлённая до 2 знаков)

None — при ошибке

💡 **get_stock_rate_list(stocks: list) -> list[dict]** формирует список цен на несколько акций.

- Параметры:

stocks — список тикеров, например ["AAPL", "GOOGL"]

- Возвращает:

[
  {"stock": "AAPL", "price": 195.32},
  {"stock": "GOOGL", "price": 145.67}
]

💡 **filter_transactions(transactions: list[dict]) -> DataFrame** фильтрует транзакции, оставляя только реальные расходы.

- Условия фильтрации:

Сумма платежа < 0 (только траты)

Категория ≠ "Наличные" и ≠ "Переводы"

Категория заполнена (не NaN)

- Возвращает:

pandas.DataFrame с отфильтрованными транзакциями.

💡 **get_card_summary(df: DataFrame) -> list[dict]** формирует сводку по банковским картам.

- Что рассчитывает для каждой карты:

last_digits — последние 4 цифры номера

total_spent — общая сумма трат (по модулю)

cashback — 1% от трат (округлённый до 2 знаков)

```
Пример результата:
[
  {
    "last_digits": "7777",
    "total_spent": 15000.0,
    "cashback": 150.0
  }
]
```

💡 **get_top_transactions(df: DataFrame, count: int = 5) -> list[dict]** возвращает топ-транзакций по сумме расходов.

- Как работает:

Сортирует транзакции по убыванию суммы (наибольшие траты сверху)

Берёт первые count (по умолчанию 5)

- Возвращает список словарей с полями:

date — дата

amount — сумма (по модулю)

category — категория

description — описание


📁 Модуль **src/views.py** — Главная страница


💡 **this_home() -> dict** формирует полную “главную страницу” с данными для фронтенда.

- Что делает:

Читает транзакции из data/operations.xlsx

Фильтрует их

Генерирует приветствие по текущему времени

Получает курсы валют (USD, EUR → RUB)

Получает цены акций (AAPL, AMZN, GOOGL, MSFT, TSLA)

Формирует сводку по картам и топ-5 транзакций

- Возвращает словарь:

```
{
  "greeting": "Добрый день",
  "cards": [...],
  "top_transactions": [...],
  "currency_rates": [...],
  "stock_prices": [...]
}
```

- Логирование:

Подробно логирует каждый шаг (уровень INFO).

📁 Модуль **src/services.py** — Бизнес-логика

💡 **analyze_cashback_by_category(data: list[dict], year: int, month: int) -> str** анализирует, сколько кэшбэка можно было бы получить по каждой категории, если бы она была “категорией повышенного кэшбэка”.

- Условия:

Только траты за указанный месяц и год

Исключены “Наличные” и “Переводы”

Кэшбэк = 1% от суммы трат

- Возвращает JSON-строку:

```
json
{
  "Еда": 150.25,
  "Транспорт": 80.0,
  "Развлечения": 45.1
}
```

- Обработка ошибок:

Проверяет диапазон месяца (1–12)

Пустые данные → возвращает пустой JSON

Ошибки при обработке → логирует, возвращает {}

💡 **investment_bank(month: str, transactions: List[Dict], limit: Any) -> str** рассчитывает сумму, отложенную в “Инвесткопилку” за счёт округления трат до заданного порога.

```
Пример:
Если тратишь 123 рубля, а limit=100, то округляется до 200 → в копилку идёт 77 рублей.
```

- Параметры:

month — месяц в формате "YYYY-MM"

transactions — список транзакций

limit — порог: 10, 50 или 100 рублей

- Возвращает JSON:

```
{"total_savings": 123.45}
```

- Особенности:

Приводит limit к int

Проверяет корректность месяца и транзакций

Фильтрует транзакции через filter_transactions

💡 **search_person_transfers() -> str** ищет переводы физическим лицам по описанию.

- Критерии:

Категория: "Переводы"

Описание соответствует паттерну: Имя Фамилия И. (например, Валерий А.)

- Использует регулярное выражение:

```
r"^[А-ЯЁ][а-яё]+\s[А-ЯЁ]\.$"

```

- Возвращает JSON-список транзакций, подходящих под критерии.

- Обработка:

Пропускает NaN, None, пустые строки

Логирует количество найденных переводов

📁 Модуль **src/reports.py** — Генерация отчётов

**Декоратор @save_report** автоматически сохраняет результат функции в JSON-файл.

- Если не указан filename — создаёт файл с временной меткой: report_2024-01-15_14-30-00.json

- Создаёт папку reports/, если её нет

- Сохраняет с отступами и кириллицей (ensure_ascii=False)

- Логирует успех или ошибку

💡 **spending_by_category(transactions: DataFrame, category: str, date: Optional[str] = None) -> str** формирует отчёт о тратах по указанной категории за последние 3 месяца.

- Параметры:

transactions — DataFrame с транзакциями

category — категория (регистронезависимо)

date — дата анализа (по умолчанию — сегодня)

- Что проверяет:

Существует ли категория?

Есть ли траты по ней?

Есть ли данные за указанный период?

- Возвращает JSON с полями:

```
{
  "category": "Еда",
  "period": {"from": "2024-01-01", "to": "2024-04-01"},
  "total": 5200.5,
  "spending": [
    {"date": "2024-01-15", "amount": 1200.0, "description": "Супермаркет"}
  ],
  "warning": "..."  // если есть
}

```

- Дополнительно:

Если категория не найдена — возвращает список всех доступных

Если данных нет — даёт подсказку с диапазоном дат

- Сохранение:

Автоматически вызывает @save_report, если передан filename.
